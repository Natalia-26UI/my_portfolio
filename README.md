# My Portfolio

A personal portfolio website built with HTML, CSS and JavaScript.

## Live sites

- GitHub Pages:https://github.com/Natalia-26UI/my_portfolio
- Vercel:https://my-portfolio-natalia-26ui.vercel.app/ 

## Pages

- **Home** (`index.html`): introduction, skills ,projects and contact form
- **Events 254** (`Events_254.html`): A one-page website for a community event.
- **My Shop** (`My_shop.html`): A simple e-commerce website for selling products online.
- **My Math Game** (`https://github.com/Natalia-26UI/my_math_game.git`):A simple math game for children to practice their arithmetic skills.

## Features

- Skills section with labelled proficiency tags
- Services section with an unorderd list
- Project cards that expand to show more details
- Contact form with JavaScript validation
- Background colour buttons

## Built with

- HTML
- CSS
- JavaScript
